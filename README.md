Entry for the [make.fun bounty "One Line to Your Younger Self"](https://make.fun/c/u-boothlord-one-line-to-your-younger-self-22e97f76): write the single line you would send your younger self if one line were all you got.

## The line

> The night you sleep on the floor with a dead phone and nothing in your pocket is the night you learn nobody's coming — and that's the best news you'll ever get.

## How it works

`main.py` deterministically writes that one line (160 characters, one sentence) to `/output/entry.txt`. No network, no secrets, no dependencies — just the line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
